# Запуск Режиссёра 2.0 одной командой

**Запуск:** двойной щелчок по `start-rezhisser.cmd` в этой папке.
Скрипт поднимает сервер в фоне, ждёт готовности и сам открывает http://127.0.0.1:7860/.
Если Режиссёр уже запущен — просто открывает браузер.

**Остановка:** двойной щелчок по `stop-rezhisser.cmd`. Закрывается только сервер из этой папки,
другие программы на Python не трогаются.

Из терминала то же самое: `start-rezhisser.cmd`, `start-rezhisser.cmd -Stop`,
другой порт — `start-rezhisser.cmd -Port 7870`, без браузера — `-NoBrowser`.

- Автозапуска нет: после перезагрузки ПК Режиссёр стартует только по щелчку.
- Журнал сервера: `%LOCALAPPDATA%\Rezhisser\server-7860.log` (и `.err`).
- Интерфейс пересобирается сам, только если нет `ui/dist`.
- Нужна готовая среда `app\env` (на этом ПК уже есть; на другом — установка Maestro через Pinokio).

**Ключи облака и помощника:** Settings → Integrations → Cloud. Пишутся в `.env`, наружу не отдаются.
