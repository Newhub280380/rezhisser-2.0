# STATUS — облачный бэкенд Maestro 4.1.1 (ветка `rezhisser-2.0-full`)

Дата: 2026-11-14. Все коммиты локальные, удалённой пары у ветки нет, `origin` не трогали.
Из Maestro ничего не удалено (`git diff --diff-filter=D main..HEAD` — пусто).

## Итог

Готово всё, что можно сделать без настоящих ключей. **Жёсткий блок:** реальные вызовы
MiniMax / fal / MuAPI не выполнялись — нужны настоящие ключи (и оплата у провайдеров).
Ключ вставляется в http://127.0.0.1:7860/ → Settings → Integrations → Cloud (пишется в `.env`).

## Как запустить

Двойной щелчок по **`start-rezhisser.cmd`** — сервер поднимается в фоне и открывается http://127.0.0.1:7860/.
Остановка — `stop-rezhisser.cmd`. Автозапуска нет. Подробно — `RUN.md`.

  получила понятный отказ. Облачная LLM ответила через адрес из `.env`.
- **Director:** настоящий `director_pipeline._submit_and_wait` завершает задачу через облако (тест).
- **Тесты:** облачные и помощника — 23/23 (`test_cloud_generation.py` 9, `test_cloud_call_sites.py` 14);
  после слияния вместе с `test_assistant_chat.py` и `test_comfyui_integration.py` — 40/40.
- **Помощник:** интерфейс собирается (`npm run build`), линтер чист; на живом сервере `/api/v1/assistant/status`

- **Wan 2.2:** эндпоинты и поля сверены с документацией fal 2026-11-14. Тесты: маршруты Wan t2v/i2v/turbo,
  запасной H3 (длина, только последний кадр, HTTP 410), отсутствие повтора на 401, сквозной `execute` задачи Studio
  через fal с подменённым HTTP — всего 43/43 облачных тестов и тестов помощника. Реальных вызовов fal не было (ключа нет).
  В живом UI: Studio и Director — «Cloud · fal — Wan 2.2», Settings — поле ключа fal, ошибок страницы нет.
- **Автопилот:** `tests/test_autopilot.py` — 7 тестов. Главный: 5 фото → mp4 с подменой fal и LLM, настоящими
  ffmpeg и Pillow. Проверяются все 7 шагов и их порядок, подписи прогресса, заливка прозрачного фона белым до апскейла,
  JPEG 3840, повтор сцены и переход на H3, ключевой кадр для сцены без фото, на выходе H.264 1080x1920.
  Ещё: сцена падает после 2 повторов, каркас ремейка, защита путей загрузок, разбор JSON, база знаний.

## Окружение этого ПК (не в git)

- `app/env`: torch 2.10.0+cpu и requirements без тяжёлых GPU-пакетов (на диске было ~8 ГБ).
  Локальная генерация здесь недоступна; для неё нужна штатная установка Maestro через Pinokio.
- `app/ffmpeg_bins`: ffmpeg 7.1.1 (gyan.dev). Maestro берёт его раньше системного ffmpeg 9.0,
  в котором удалены `-vsync` и `-filter_complex_script` — без этого не работали экспорт Editor и склейка Director.
- Maestro сейчас запущен через `start-rezhisser.cmd` на порту 7860; после перезагрузки ПК сам не стартует
  (автозапуск по условию не настраивался).
- Готовая коробка — сама эта папка: в zip не упаковывалась, потому что `app/env` весит несколько ГБ, а свободно около 8 ГБ.

## Что осталось

1. **Настоящие ключи** MiniMax / fal / MuAPI и облачной LLM (она же мозг помощника, OpenRouter) — жёсткий блок,
   нужен ввод владельца. После этого — один реальный прогон на каждого провайдера и один диалог с помощником.
2. **Ключ LLM (OpenRouter)** нужен автопилоту для раскадровки и помощнику для диалога — сейчас не задан (ключ fal задан).
   Для `viral_remake` модель должна понимать картинки; модель по умолчанию `nvidia/nemotron-3.5-lightning:free`
   на это не проверялась.
3. **Автопилот, чего пока нет:** подписи из раскадровки не впечатываются в кадр, музыки и озвучки нет, crossfade нет
   (жёсткий монтаж — допустимый вариант рецепта). Сцена длиннее 10 с укорачивается до 10 (предел Wan), а не делится на 2 клипа.
   В ремейке нет face swap (герой подставляется стартовым кадром) и звука исходника.
   FlashVSR не используется: он для видео и требует GPU. Стоимость: ролик на 150 с — это 15–30 платных сцен Wan.
4. **Ключ fal** для Wan 2.2: получить на https://fal.ai/dashboard/keys, вставить в Settings → Integrations → Cloud.
   fal пишет, что Wan 2.2 снимут 2027-01-04; после этого видео само уйдёт на MiniMax H3 (fal).
   В `.env.example` нет строк `CLOUD_VIDEO_ENGINE` / `FAL_WAN_*` — файлы `.env*` закрыты для агента правилами доступа.
5. Поля MuAPI `minimax-h3-image` в документации не описаны; при ошибке 4xx меняется `MUAPI_IMAGE_MODEL` в `.env`.
6. В галерее остались две плитки «Generation Failed» от тестов на заглушке; удаление записей через API
   заблокировано правилами доступа — закрываются крестиком на плитке.
7. Временная рабочая копия `main` для сравнения тестов: `%TEMP%\cloudmock\base` (git worktree);
   не удалял, потому что в ней ссылки на настоящие `ui/node_modules` и `ui/dist`.
8. Музыка Director, TTS и прочие аудио-модели — только локально (облачные провайдеры для них не заказывались).
