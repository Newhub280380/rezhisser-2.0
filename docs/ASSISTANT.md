# Встроенный помощник Режиссёра 2.0

Эта ветка `rezhisser-2.0-assistant` добавляет чат-помощника, который сам нажимает кнопки внутри приложения. Готовый агент Imagination Studio и примеры CopilotKit лежат рядом, в папках на компьютере, их не копировали целиком в этот проект.

## Где смотреть

- Кнопка «Помощник» в правом нижнем углу окна Режиссёра.
- Код интерфейса: `ui/src/assistant/`
- Мозг и ключи: `app/services/assistant_chat.py`
- Проверка: `tests/test_assistant_chat.py`

Категории в библиотеке знаний: «Замена лица», «Видео по фото», «Текст в видео».

Действия помощника: открыть экран, загрузить фото, выставить параметры, запустить генерацию, следить за очередью, отдать готовый файл.

## Ключ

Ключ OpenRouter берётся из настроек: Настройки → Integrations → Cloud, поля облачной LLM (`LLM_API_KEY`, `LLM_BASE_URL`, `LLM_MODEL`). Сами ключи в код не кладутся и в ответах сервера не возвращаются.

Если модель не указана, используется бесплатная `nvidia/nemotron-3.5-lightning:free`. Если она занята или недоступна, берётся запасная `z-ai/glm-5.3-flash`.

Адрес по умолчанию: `https://openrouter.ai/api/v1`.

## Что не делается само

Помощник не стартует вместе с Windows и не поднимается фоновой службой. Он появляется только когда открыт Режиссёр.
