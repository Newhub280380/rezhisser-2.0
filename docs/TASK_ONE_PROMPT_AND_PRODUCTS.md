## Пункт 1. Режим «одним промптом» (one_prompt_film)
Образец: Dreamina / 即梦 Drama Studio (ByteDance, ноябрь 2026). Описание подхода и этапов: docs/assistant-knowledge/recipes/one_prompt_film.md — прочитай первым.
Человек пишет ОДНУ фразу («ролик 30 секунд про ZISHÉL Glam для врачей», «история про кота-повара на 1 минуту») — помощник сам делает всё до готового mp4:
1. Сценарист (LLM помощника: OpenRouter free / GLM): фраза → 3 варианта идеи → выбор лучшего (или спросить пользователя одним вопросом, если включено) → сценарий с хуком в первые 2 с, текстом озвучки и списком сцен.
2. «Сценарный доктор»: вторым проходом LLM проверяет сценарий (хук, логика, длина, соответствие правилам базы) и сам исправляет.
3. Активы: персонажи/локации/товар → по одному дословному описанию на каждого (одинаково во всех сценах); если в запросе товар Beautyart — брать РЕАЛЬНОЕ фото из products/refs/ours (см. пункт 2), не генерировать упаковку.
4. Раскадровка JSON: сцены по 5–10 с (план, движение камеры, действие, промпт Wan 2.2 по формуле из rules.md, негатив, длительность, текст озвучки на сцену).
5. Черновик: ключевой кадр каждой сцены картинкой (дёшево), затем Wan 2.2 image-to-video на fal, 480p черновик; финал 720p по флагу.
6. Озвучка: TTS Kokoro через fal (ключ fal уже в настройках); запасной бесплатный локальный (edge-tts или Piper). Русский язык.
7. Музыка: бесплатная фоновая (библиотека без роялти в app/data или генерация, если есть дешёвая модель на fal), громкость под голосом около −18 dB.
8. Субтитры: SRT из текста озвучки с таймингами по длительности аудио, вшить крупным шрифтом с кириллицей.
9. Склейка ffmpeg: сцены + xfade, озвучка, музыка, субтитры, 1080×1920 H.264 (или 1920×1080 по запросу) → mp4.
10. Перегенерация одной сцены без пересборки всего ролика (как «片段重拍» у образца).
Сделать: новый рецепт one_prompt_film в recipes.json + категория в интерфейсе помощника («Одной фразой»), конвейер в бэкенде (переиспользуй то, что уже есть для photo_to_film: Wan 2.2 на fal, склейка), прогресс по этапам в интерфейсе, тесты без реальных сетевых вызовов (моки fal/TTS). Один реальный тест на 10–15 с можно, черновик 480p (каждые 5 с Wan 2.2 ≈ 0,2 $).
