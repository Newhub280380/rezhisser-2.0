# База знаний помощника Режиссёра 2.0

Источник: три файла Александра из «Загрузок» (14.11.2026), лежат в `sources/` без изменений.
- `sources/asia-ai-video-playbook.md` — полный мануал: конвейер из 5 шагов, формула промпта, словарь камеры, шпаргалки по моделям, 12 приёмов против «рулетки», жанры, траблшутинг.
- `sources/slash-commands.md` — библиотека slash-команд: зафиксированные шаблоны, менять только `[поля в скобках]`.
- `sources/hub-map.md` — где брать готовые промпты и как разбирать чужой ролик в промпт (вирусный ремейк).

Структура:
- `recipes.json` — машинно-читаемые рецепты автопилота (категории, шаги, инструменты, шаблоны промптов, правила). Это то, что подключается к помощнику.
- `recipes/*.md` — те же рецепты человеческим языком, по одному файлу на категорию.
- `rules.md` — общие правила промптинга и анти-рулетки, которые помощник применяет на каждом шаге.
- `slash-commands.json` — все slash-команды из библиотеки в виде шаблонов с полями.

Движок по умолчанию: Wan 2.2 через fal. Запасной: MiniMax H3. Ключи только из настроек приложения, в базе их нет.
