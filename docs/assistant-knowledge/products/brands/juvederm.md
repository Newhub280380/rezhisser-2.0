# Juvéderm (Allergan Aesthetics / AbbVie)

Связано: [cards/leader-patterns.md](../cards/leader-patterns.md)

Самая известная линейка ГК-филлеров (Voluma, Volbella, Volift, Ultra). Шприцы 1 мл в белых коробках, у каждой подлинейки свой цвет полосы. На сайте: шприц вертикально в центре на коралловом фоне, капля геля падает с иглы; портреты разных возрастов.
