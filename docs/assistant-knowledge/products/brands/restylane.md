# Restylane (Galderma)

Связано: [cards/leader-patterns.md](../cards/leader-patterns.md)

Шведская линейка ГК-филлеров и скинбустеров (Lyft, Kysse, Defyne, Refyne, Skinboosters). Коробки белые с фиолетово-розовыми акцентами, логотип рукописный. Подаёт продукты «семейством». Своих открытых пакшотов скачать не удалось — ориентир по описанию.

## Что взять для Beautyart
- Приём подачи (свет, фон, крупность), но не подиумы и не чужие надписи.
