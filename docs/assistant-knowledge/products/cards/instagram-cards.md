# Карточки для Instagram (врачам)

Связано: [rules/beautyart-card-rules.md](../rules/beautyart-card-rules.md), [ours/zishel-glam.md](../ours/zishel-glam.md)

## Форматы
- Пост/карусель: 1080×1350 (4:5). Поля 64–80 px.
- Сторис/Reels-обложка: 1080×1920 (9:16). Без текста в верхних 250 px и нижних 300 px.

## Шаблон поста товара (Beautyart)
- Сверху плашка «Зарегистрировано на территории Республики Казахстан» (только ZISHÉL).
- Заголовок: название + объём («ZISHÉL Glam · 10 мл»).
- Одна строка пользы/показаний.
- Товар 55–65% высоты, по центру или чуть ниже.
- Внизу подпись «Beautyart».

## Карусель из 5 слайдов (пример для ZISHÉL Glam)
1. Обложка: товар + «ZISHÉL Glam».
2. «8 лет успешного применения».
3. «Тысячи довольных пациентов».
4. «Официальная регистрация в РК».
5. «Универсальный филлер для контурной пластики» + призыв написать в директ.

## Палитра
- ZISHÉL: розово-перламутровый / жемчужно-телесный с серебром; допустим глубокий графит для контраста.
- MELAGENTA: пудрово-розовый, молочный или глубокий винно-ягодный.
- Sagitta: холодный фиолетовый + белый.

## Шрифты
Антиква/дидон для названия (Cormorant Garamond, Playfair Display), гротеск для текста (Manrope, Montserrat, Inter), кириллица обязательна.
