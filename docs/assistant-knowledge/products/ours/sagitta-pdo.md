# Нити PDO Sagitta

Связано: [categories/pdo-threads.md](../categories/pdo-threads.md)

## Что это
Лифтинг-нити PDO Sagitta (основная позиция — The Fishbone, нить с насечками «ёлочка» для подтяжки). Производитель Unimaster (Китай). Плашку РК НЕ ставить.
Строка на карточку: «Нитевая подтяжка лица и тела».

## Как выглядит
Фиолетовая коробка с крупной белой надписью «THREAD LIFTING» вертикально, логотип Sagitta, подпись «Unique as beauty master». Внутри — стерильные конверты с канюлей и фиолетовой нитью.
