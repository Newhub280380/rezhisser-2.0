# Рецепт: короткий ролик с товаром (Wan 2.2 / fal)

Связано: [rules/beautyart-card-rules.md](../rules/beautyart-card-rules.md), ../../recipes/photo_to_video.md

Принцип: товар ВСЕГДА из реального фото (image-to-video), не text-to-video. Упаковку не перерисовывать.

## Шаги
1. Взять реальное фото из `refs/ours/`, убрать фон, поставить на чистый студийный фон из палитры (без подиума).
2. Ключевой кадр 9:16, товар 55–65% высоты.
3. Оживить 4–5 с, одно слабое движение камеры.
4. 3–4 таких клипа + титры по 1–3 слова + озвучка + музыка → склейка 15–30 с.

## Промпты (Wan 2.2, через запятую)
- "slow dolly push in, premium cosmetic box standing on clean seamless pearl background, soft studio light, gentle contact shadow, subtle reflection, product geometry unchanged, keep label identical, photorealistic"
- "slow orbit 20 degrees around the box, same background, soft light sweep across the silver surface, product unchanged"
- "macro close-up of the box logo, light glint moving, shallow depth of field, product unchanged"
Негатив: "pedestal, podium, stand, flowers, extra text, deformed box, melted label, warped letters, watermark, blurry".

## Титры (примеры для ZISHÉL Glam)
«8 лет применения» → «Тысячи пациентов» → «Регистрация в РК» → «ZISHÉL Glam».
