# Рецепт: «одним промптом» (по образцу Dreamina / 即梦 Drama Studio, ByteDance)

## Как устроен образец (ноябрь 2026)
即梦 (Китай, 26.10.2026) и Dreamina Drama Studio (мир, 09.11.2026): одна фраза → готовый ролик/серия. Конвейер из отдельных моделей и агентов на ОДНОМ общем проекте:
1. DreamScript (сценарная модель): фраза или теги жанра → 3 варианта идеи → синопсис → поэпизодный план → сценарий с репликами. «Сценарный доктор» оценивает (C/B/A/S), ищет дыры и сам исправляет. Хук в первые секунды.
2. Разбор активов: из сценария автоматически извлекаются персонажи, локации, реквизит → для каждого пишется промпт → генерируются «паспортные» картинки (Anycook). Это общая библиотека, к ней всё обращается через @ссылку — так держится одинаковое лицо/одежда во всех сценах.
3. DreamShot (раскадровка): сценарий + активы → список кадров (план, ракурс, движение камеры, реплика, длительность), нарезка под лимит видеомодели (15 или 30 с на кусок).
4. «Умное превью»: сначала дешёвые стоп-кадры/черновик 480p всей сцены, проверка ритма → только потом полная генерация (экономия до 60%).
5. Генерация видео Seedance 2.5 (до 30 с за раз, мульти-референсы, правка по таймкодам) → апскейл 480p→4K.
6. Многодорожечный монтаж: склейка, отделение звука и переозвучка, BGM, авто-субтитры, перегенерация одного куска.
Открытого кода у Drama Studio нет. API есть только у видеомодели: Seedance 2.5 через BytePlus ModelArk (с 15.11.2026), Seedance также есть на fal.

## Наш аналог (бесплатно/дёшево)
Фраза → LLM-сценарист (OpenRouter free / GLM) → самопроверка «доктор» → активы (ключевые кадры картинкой, один персонаж = одно дословное описание) → раскадровка JSON (5–10 с на сцену) → черновик 480p → Wan 2.2 image-to-video на fal → озвучка TTS (Kokoro на fal, запасной edge-tts/Piper) → музыка (бесплатная библиотека или генерация) → субтитры из текста озвучки (SRT) → склейка ffmpeg (xfade, громкость музыки под голосом −18 dB, 9:16, H.264) → mp4.
