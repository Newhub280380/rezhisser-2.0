# Фото → мини-ролик (автопилот)

5 фото и одна фраза → готовый mp4 на 1–3 минуты.

Как человек просит: «вот 5 фото, сделай мини-ролик на 2–3 минуты»; «собери ролик из этих фото»; «сделай рекламу из фото товара»

## Что нужно
- photos: 1–20 фото
- total_seconds: по умолчанию 60; «2–3 минуты» = 150
- aspect: 9:16 по умолчанию для соцсетей
- style: из фразы человека или /hero по умолчанию

## Шаги
1. `remove_background` — Убрать фон с фото — когда: если объект/продукт/человек нужно перенести в новую сцену; для пейзажей и интерьеров пропустить
2. `upscale_image` — Улучшить фото и поднять до 4К (длинная сторона 3840) — {"target_long_side": 3840}
3. `convert_jpeg` — Перевести в JPEG (quality 95, sRGB, без альфы: прозрачный фон заливать белым или фоном сцены) — {"quality": 95}
4. `write_storyboard` — LLM пишет раскадровку: список сцен по 5–10 с, на каждую промпт по правилам модели — {"scene_seconds": "5–10", "prompt_template": "storyboard_prompt"}
5. `generate_keyframe` — Ключевой кадр картинкой, если для сцены нет подходящего фото — когда: для сцен с photo_index = null
6. `generate_scene` — Оживить кадр в клип — {"engine": "wan2.2_fal", "resolution": "480p черновик → 720p финал", "seconds": "5 (Wan); длинные сцены = 2 клипа", "negative_prompt": "blurry, low quality, deformed hands, morphing face, extra limbs, flicker, jitter, text artifacts, watermark, cartoon"}
7. `concat_clips` — Склеить клипы, переходы, музыка/озвучка, субтитры, экспорт — {"transitions": "короткий crossfade 0.3 с или жёсткий монтаж", "captions": "из storyboard.caption", "export": "mp4 H.264"}

## Прогресс для человека
- Убираю фон
- Улучшаю до 4К
- Перевожу в JPEG
- Пишу раскадровку
- Генерирую сцену {i} из {n}
- Склеиваю
- Готово

## Правила
- Сначала картинка, потом видео
- Одна сцена = одно действие + одно движение камеры
- Одинаковое описание персонажа/продукта во всех сценах
- Черновик 480p, финал по запросу

## Промпт раскадровки
```
Ты режиссёр рекламных роликов. Дано: {n_photos} фото (описания: {photo_notes}), задача: «{user_request}», длительность {total_seconds} с, формат {aspect}. Разбей на сцены по 5–10 с (одна сцена = одно действие + одно движение камеры). Первые 2 секунды — хук. Последняя сцена — развязка/CTA. Каждой сцене назначь исходное фото (photo_index) или null, если нужен новый кадр. Персонажа и продукт описывай дословно одинаково во всех сценах. Промпт сцены для Wan 2.2 пиши тегами через запятую, глагол камеры первым. Верни JSON: {"scenes":[{"index":1,"seconds":5,"photo_index":1,"camera":"slow dolly push in","action":"...","prompt":"...","negative_prompt":"...","caption":"до 3 слов или пусто"}],"music_mood":"...","voiceover":"текст или пусто"}
```
