# Текст в видео

Ролик по описанию без фото: сначала ключевой кадр, потом оживление.

## Шаги
1. `write_storyboard` — LLM пишет раскадровку: список сцен по 5–10 с, на каждую промпт по правилам модели — когда: если ролик длиннее 10 с
2. `generate_keyframe` — Ключевой кадр картинкой, если для сцены нет подходящего фото
3. `generate_scene` — Оживить кадр в клип
4. `concat_clips` — Склеить клипы, переходы, музыка/озвучка, субтитры, экспорт — когда: если сцен больше одной

## Шаблон промпта
```
{camera}, {subject}, {action}, {place}, {light}, {style}, cinematic, photorealistic
```

## Правила
- Не доверять внешний вид чистому text-to-video — сначала ключевой кадр
