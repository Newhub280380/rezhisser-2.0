# Вирусный ремейк

Найти/взять вирусный ролик, разобрать в промпт, заменить людей/продукт, сгенерировать новый.

## Что нужно
- source: ссылка на ролик или тема для поиска трендов
- replace: фото своего человека/продукта

## Шаги
1. `fetch_video` — Скачать ролик по ссылке (TikTok/Instagram/YouTube)
2. `extract_frames` — Нарезать стоп-кадры и сцены из ролика — {"mode": "scene detect, 1 стоп-кадр на сцену"}
3. `video_to_prompt` — Разобрать ролик/стоп-кадры в промпт: камера / действие / свет / звук / темп — {"prompt": "Разбери этот кадр/ролик как промпт-инженер: камера / действие / свет / звук / темп. Затем версия, где вместо [ОБЪЕКТ] — объект с прикреплённого фото. Всё остальное не менять."}
4. `face_swap` — Заменить лицо на фото/видео — когда: если нужно заменить человека на стоп-кадрах
5. `generate_scene` — Оживить кадр в клип — {"engine": "wan2.2_fal", "source": "новые ключевые кадры"}
6. `concat_clips` — Склеить клипы, переходы, музыка/озвучка, субтитры, экспорт — {"audio": "ритм исходника управляет монтажом"}

## Правила
- Менять ТОЛЬКО объект/персонажа, свет, камеру и стиль оставлять
- Удачный промпт сохранять в копилку команд
