# Общие правила (применять на каждом шаге)

## Конвейер (порядок не менять)
Идея/сценарий (LLM) → ключевой кадр картинкой → оживление image-to-video → звук → склейка, субтитры, хук в первые 2 секунды.
«Никогда не анимируй до того, как зафиксировал визуал». Не начинать важный ролик с чистого text-to-video.

## Формула промпта для видео
[КАМЕРА: глагол движения] + [КТО: 2–3 признака] + [ЧТО ДЕЛАЕТ: один глагол] + [ГДЕ] + [СВЕТ: один] + [СТИЛЬ: один]

## Золотые правила
1. Глагол камеры в первых 8–10 словах.
2. Только кинематографические глаголы: slow dolly push in, truck left/right, pan, tilt, crane up, orbit around, tracking shot, handheld, static shot, dolly zoom, whip pan, macro close-up.
3. Одно движение камеры + максимум один мягкий модификатор.
4. Одно действие субъекта на клип, 4–8 секунд на клип.
5. Ограничения формулировать позитивно: "product geometry unchanged", "keep silhouette identical", "both hands remain visible".
6. Персонажа описывать ДОСЛОВНО одинаково во всех сценах серии.
7. Один стиль на промпт.
8. Текст в кадре — 1–3 слова, в двойных кавычках, bold plain font.
9. Слабое движение лучше сильного: subtle / slow / micro.
10. Не понравилось — менять ровно одну переменную (только камера, или только действие, или только фото).
11. Черновик дёшево (480p), финал дороже (720p/1080p). Закладывать 2–4 дубля на важный кадр.

## Стиль промпта по модели
- Wan 2.2 (по умолчанию): как теги датасета, через запятые; негативный промпт полезен (blurry, deformed hands, morphing face, extra limbs, flicker, text artifacts, watermark).
- MiniMax H3 / Hailuo (запасной): проза до ~40 слов, команда камеры в квадратных скобках в начале, `[Push in] ...`, БЕЗ негативного промпта. Анатомия действия подробно. От мультяшности: "photorealistic, shot on Arri Alexa, cinematic movie style, natural lighting".
- Kling: Multi-Shot с таймкодами `Shot 1 (0–3s): ...`, референсы `@Image1`, `@Element1`.
- Vidu Q3: сцена → персонаж → действие → камера → звук; реплики в кавычках, ≤2.5 слова/сек.

## Траблшутинг (симптом → фикс)
- Деревянное движение → активный глагол в начало, одно движение камеры.
- Камера не та → команда камеры в первые 8–10 слов, одна.
- Плавление/морфинг → одно действие на 4–6 с, "hands remain completely still".
- Лицо меняется → дословно одинаковое описание + референсы.
- Кракозябры → 1–3 слова в кавычках.
- Мультяшно → photorealistic, shot on Arri Alexa, natural lighting.
- Продукт деформируется → subtle/slow/micro + keep silhouette identical, клип до 4 с.
- Совсем мусор → взять удачный стоп-кадр и прогнать image-to-video вместо text-to-video.

## Экспорт
Вертикаль 1080×1920 (9:16), H.264, 15–20 Mbps. Для горизонтали 1920×1080.
