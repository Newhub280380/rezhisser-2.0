# 🗺 КАРТА ХАБОВ: где брать готовые промпты и как красть стиль из чужих работ

Логика простая: **видишь результат → копируешь промпт под ним → подставляешь своё фото/товар → получаешь то же самое со своим контентом.**

## 2️⃣ Картинки-хабы: кликнул картинку → увидел промпт

| Где | Фишка |
|---|---|
| **LiblibAI / 哩布哩布** (liblib.art) 🇨🇳 | Главный китайский хаб (аналог C-станции): фото, косметика, реклама, китайский стиль — клик по работе открывает промпт [2](https://zhuanlan.zhihu.com/p/662517191). Включи переводчик браузера |
| **TusiArt / 吐司** (tusi.art) 🇨🇳 | Китайский хаб картинок: промпты открыты + кнопка «сделать так же» в один клик [1](https://www.ainav.cn/sites/1387.html) |
| **Civitai** (civitai.com) | Крупнейший мировой хаб: промпт + модель + все параметры под каждой картинкой |
| **OpenArt.ai** | Промпты + рабочие процессы, есть поиск по картинке |
| **PromptHero** (prompthero.com) | Галерея Midjourney/SD/DALL-E с промптами, есть фильтры по нишам (продукт, еда, косметика) |
| **Lexica** (lexica.art) | Поиск по визуальному стилю, промпты открыты |
| **midjourney.com/showcase** | Официальная витрина: промпты видны участникам |
| **PromptBase** (promptbase.com) | Маркет: продаются отполированные промпты под конкретные стили ($2–5), когда нужен гарантированный «стиль французской косметики» без подбора |

**Как это выглядит на практике (твой пример с французской косметикой):**
1. На PromptHero / Civitai / LiblibAI в поиске: `cosmetic product photography` → выбираешь картинку, где «красиво и вкусно».
2. Клик → копируешь промпт целиком.
3. В промпте меняешь только название/описание продукта на свой + прикладываешь фото своего товара как референс (в Seedream / Gemini: *«Replace the product in the image with the product from the reference photo, keep everything else unchanged»*).
4. Готово: Франция, но с твоим товаром. Сеттинг, свет, композиция — из чужого рабочего промпта.

## 3️⃣ Реверс-инструменты: отдаёшь видео/картинку — получаешь промпт

Для случаев, когда работа не из хаба, а просто увидел ролик в ленте и хочешь такой же.

| Инструмент | Что делает |
|---|---|
| **vid2prompt.com** | Вставляешь ссылку на TikTok / Instagram / YouTube → через ~30 сек получаешь структурированный промпт под Sora / Seedance / Kling; понимает английский и китайский, есть бесплатная попытка [4](https://vid2prompt.com/?lang=en) |
| **videotoprompt.app** | Загружаешь клип или ссылку → отдаёт ДВА промпта: покадровый (для картинки) и видео-промпт (движение + камера + темп); есть посценный режим для длинных роликов [3](https://www.videotoprompt.app/tools/video-prompt-extractor) |
| **videoinprompt.com** | Видео или картинка → промпт + JSON-метаданные (ключевые кадры, движение) под Runway / Sora / MJ [2](https://videoinprompt.com/) |
| **promptreverse.app** | Полный цикл: картинка/видео → промпт → тут же генерация своего варианта на Seedream / Kling / Veo; все промпты копятся в твою личную библиотеку [5](https://promptreverse.app/) |
| **noteai.io** | Видео → детальный промпт под Midjourney / SD (стили, свет, ракурсы) [1](https://www.noteai.io/extract-prompt-from-video) |

**Бесплатный лайфхак без отдельных сайтов:** кидаешь картинку или стоп-кадр видео в любой мультимодальный чат-бот (Gemini, ChatGPT, Kimi, Qwen) и пишешь:
```
Разбери это изображение как промпт-инженер. Напиши детальный промпт
на английском, который воссоздаст эту же картинку: субъект, композиция,
свет, объектив, цвета, стиль, атмосфера. Затем сделай версию промпта,
где вместо [МОЙ ПРОДУКТ] используется мой товар с прикреплённого фото.
```
Для видео то же самое: попроси разложить по блокам «камера / действие / свет / звук / темп».

**Важно понимать:** ни один инструмент не достаёт из файла БУКВАЛЬНЫЙ исходный промпт — его там нет. Это всегда точная реконструкция: стиль, свет, камера и движение описываются достаточно, чтобы получить такой же тип результата [3](https://www.videotoprompt.app/tools/video-prompt-extractor). Для твоей задачи «тип результата тот же, только мой товар» — этого достаточно.

## 4️⃣ Твой рабочий конвейер (итоговая сборка)

```
1. Нашёл работу, которая нравится
      ├─ в хабе → копируешь промпт из-под неё (раздел 1–2)
      └─ в ленте → прогоняешь через вид2промпт-сервис (раздел 3)
2. В промпте меняешь ТОЛЬКО: объект/товар/персонажа на свой
   (всё остальное — свет, камера, стиль — остаётся нетронутым)
3. Свой товар прикладываешь фото-референсом (режим «заменить продукт»
   в Seedream / Gemini / Kling Elements)
4. Генеришь. Совпало по типу → масштабируешь на серию.
```

Каждый удачный украденный промпт сохраняй в свою копилку — через месяц у тебя будет личная библиотека «команд», заточенная именно под твой товар и стиль.
